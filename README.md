# OncoPrimer (Beta)

Oncology treatment-pathways reference for clinicians: regimens, approvals and new data by disease group, with links to the sources.

**Reference only, not treatment advice.** It can be inaccurate or out of date and is not checked against NCCN. Confirm everything in the primary source before use.

Designed and maintained by Chao Yin.

Live app: https://chowdown89.github.io/oncoprimer-app/
